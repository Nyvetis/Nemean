# Nemean

Created by @Nyvetis to learn about Kotlin and minecraft modding, especially in Hypixel Skyblock.

Nemean is goint to be a QoL (Quality of Life) skyblock mod, and i am not planning to make it a cheat, because thats boring.

Remember that all mods are `use at your own risk`.

As a junior developper, i am not the greatest dev to make things that always work, so Nemean will start slowly, don't expect much.
